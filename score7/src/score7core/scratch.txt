Example program flow

Score7Core game = new Score7Core();

game.addPlayer("Alice");
game.addPlayer("Bob");
game.addPlayer("Steve");

game.addCard("Alice", Cards.TWO);
game.addCard("Bob", Cards.NINE);
game.addCard("Steve", Cards.FIVE);
game.addCard("Alice", Cards.TWO); // alice should now bust (her score for the ROUND) is 0
game.addCard("Bob", Cards.FIVE);
game.addCard("Steve", Cards.SIX);
game.action("Bob", Action.STAY); // bob is out and safe for the round, keeping his score
game.addCard("Steve", Cards.ONE);
game.action("Steve", Action.STAY);

now the round should increment and we do it all again. Of course
in a real program this would be in a event loop calling these action from user input.
